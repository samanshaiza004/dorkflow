# Decision log

Copy `decision-template.md` for each meaningful human choice and give the
copy a stable filename such as `001-navigation.md`. Keep previous records;
when a choice changes, add a new record and name the earlier decision under
**Supersedes**. This keeps the rationale visible instead of silently
rewriting project history.

Decisions record taste and tradeoffs owned by the human. They can refer to
profile layer IDs, reference IDs, evidence, or project requirements. A
decision does not need to answer every field when a field is not relevant.
