# Future Design Profile work — deferred

This note preserves possible extensions without making them part of the
minimal reusable profile milestone. The starter must be useful before a user
adds personal references or completes any elicitation.

Deferred ideas include:

- guided taste setup, including **3 loves / 2 dislikes / 1 intriguing**;
- pairwise preference elicitation;
- human-approved Compass principles inferred from repeated decisions;
- Atlas completeness or coverage-gap reporting by design domain;
- semantic and visual reference retrieval;
- historical, contemporary, wildcard, and anti-reference shortlists;
- retrieval of personal project-decision history in later work;
- profile evolution from repeated accepted/rejected decisions;
- external or remote media stores;
- MCP exposure and GitHub-native account integration;
- shared/team profiles and profile inheritance;
- automatic Atlas indexing, embeddings, and recommendation.

Do not infer taste or modify a profile automatically. Any later inferred
principle must be reviewable and approved by a human before it becomes active.
No database, questionnaire, retrieval service, cloud sync, or universal taste
score is part of this milestone.
