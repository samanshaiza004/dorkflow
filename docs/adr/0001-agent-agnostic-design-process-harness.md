# Dorkflow is a design-process harness

Dorkflow's product direction is an agent-agnostic design-process harness, not an autonomous website designer. The current system-recovery experiment remains a subsystem that tests whether agents can infer deliberate design decisions from structural evidence; the larger workflow connects human intent, structural and perceptual evidence, candidate directions, critique, human decisions, implementation, and deterministic verification through inspectable artifacts and gates. This preserves the valuable Phase A work while testing whether a disciplined process improves outcomes beyond a strong frontend-design prompt alone.
